# ระบบบริหารจัดการข้อมูลและสถานการณ์อุทกภัยระดับจังหวัด (Provincial Health & Flood System)
> ระบบลงทะเบียน เข้าสู่ระบบ จัดการสิทธิ์ (CRUD) และบันทึกรายงานสถานการณ์อุทกภัยด้านการแพทย์และสาธารณสุข จังหวัดอ่างทอง (รพ.สต., สสอ., โรงพยาบาล) **จำแนกรายหมู่บ้าน แยกตามล็อกหัวข้อตรงตามแบบรายงานราชการ** พร้อมระบบสรุปยอดภาพรวมจังหวัดสำหรับ Admin และระบบบันทึก Audit Logs (NOW())

---

## 🌟 คุณสมบัติเด่นของระบบที่พัฒนาตามข้อกำหนด

1. **เฉพาะหน่วยงานด้านสาธารณสุข (Health Facilities Only):**
   - คัดกรองและจัดเก็บเฉพาะหน่วยงาน 3 ประเภทหลักตามคำสั่ง:
     - **รพ.สต.** (โรงพยาบาลส่งเสริมสุขภาพตำบล ทั้งหมด 44 แห่ง)
     - **สสอ.** (สำนักงานสาธารณสุขอำเภอ ทั้ง 7 อำเภอ)
     - **โรงพยาบาล** (รพท. / รพช. ทั้ง 7 อำเภอ: รพ.อ่างทอง, รพ.ไชโย, รพ.ป่าโมก, รพ.โพธิ์ทอง, รพ.แสวงหา, รพ.วิเศษชัยชาญ, รพ.สามโก้)
     - *(และ สสจ.อ่างทอง สำหรับผู้บริหารและ Admin)*
   - Chained Dropdown สองชั้น เลือกอำเภอแล้วดึงเฉพาะหน่วยงานสาธารณสุขในอำเภอนั้น ไม่มี อบต./เทศบาล มาปะปน

2. **การบันทึกข้อมูลแบ่งเป็นหมู่บ้าน และแยกเป็นล็อกๆ ตามหัวข้อแบบในไฟล์ (`report_entry.php`):**
   - วิเคราะห์และถอดโครงสร้างข้อมูลจากไฟล์ Excel `7. อำเภอสามโก้_แบบรายงานสถานการณ์อุทกภัย 2569.xlsx` และตัวอย่าง UI:
   - **แบ่งตามล็อกหัวข้อ (Topic Blocks):**
     - **🛏️ ล็อก 1: ผู้ป่วยติดเตียง** (จำนวนทั้งหมด, น้ำท่วม, การช่วยเหลืออยู่บ้าน, ศูนย์พักพิง, ส่งต่อ รพ.)
     - **🩺 ล็อก 2: ผู้ป่วยฟอกไต** (จำนวนทั้งหมด, น้ำท่วม, อยู่บ้าน, อพยพ, ปัญหาขาดการฟอกไต)
     - **🧠 ล็อก 3: จิตเวช (รับยา)** (จำนวนทั้งหมด, น้ำท่วม, อยู่บ้าน, อพยพ, พบปัญหาสุขภาพ)
     - **👵 ล็อก 4: ผู้สูงอายุ 60 ปีขึ้นไป** (จำนวนทั้งหมด, น้ำท่วม, อยู่บ้าน, อพยพ, มีโรคประจำตัว/ขาดยา)
     - **♿ ล็อก 5: ผู้พิการ** (จำนวนทั้งหมด, น้ำท่วม, อยู่บ้าน, อพยพ, พบปัญหาสุขภาพ)
     - **💊 ล็อก 6: โรคเรื้อรัง (NCD)** (จำนวนทั้งหมด, น้ำท่วม, อยู่บ้าน, อพยพ, ขาดยาประจำตัว)
     - **🤰 ล็อก 7: หญิงตั้งครรภ์** (จำนวนทั้งหมด, น้ำท่วม, อยู่บ้าน, อพยพ, เสี่ยงใกล้คลอด/มีปัญหา)
     - **👶 ล็อก 8: เด็กอายุ 0-5 ปี** (จำนวนทั้งหมด, น้ำท่วม, อยู่บ้าน, อพยพ, พบปัญหาเจ็บป่วย)
     - **🚑 ล็อก 9: ทีมปฏิบัติการ & การแพทย์เคลื่อนที่** (หน่วยแพทย์เคลื่อนที่, MCATT เยียวยาจิตใจ, SRRT, เยี่ยมบ้าน, จ่ายยา, PFA)
   - **บันทึกแยกรายหมู่บ้าน (Village Granularity):**
     - แสดงแถวตารางแยกตามรายหมู่บ้าน (หมู่ที่ 1, หมู่ที่ 2, ... จนครบทุกหมู่ของตำบล)
     - สามารถกด **"+ เพิ่มหมู่บ้าน"** หรือลบหมู่บ้านได้อิสระ
     - คำนวณผลรวมของแต่ละคอลัมน์แบบ Real-time ทั้งระดับตำบลและระดับหน่วยงาน
     - บันทึกลงตาราง `flood_report_villages` สำหรับข้อมูลรายหมู่บ้าน และคำนวณ Rollup Sums บันทึกลงตาราง `flood_reports` อัตโนมัติ

3. **ระบบดูข้อมูลภาพรวมจังหวัดอ่างทองสำหรับ Admin (`provincial_overview.php`):**
   - เข้าถึงได้เฉพาะสิทธิ์ `admin` (เช่น ผู้บริหาร สสจ.) และ `superadmin`
   - **เลือกดูตามวันที่ของรายงาน (Report Date):** สรุปยอดสะสมของวันนั้นๆ ได้ทันที
   - **KPI สรุปยอดทั้งจังหวัด:**
     - จำนวนหน่วยงานที่ส่งรายงานแล้ววันนี้ / ทั้งหมด (คิดเป็น %)
     - จำนวนสถานบริการที่ได้รับผลกระทบ
     - ยอดรวมผู้ป่วยกลุ่มเปราะบางในพื้นที่น้ำท่วมทั้งจังหวัด
     - ประชาชนที่ได้รับบริการทางการแพทย์
   - **ตารางสรุปเปรียบเทียบ 7 อำเภอ:** (เมืองอ่างทอง, ไชโย, ป่าโมก, โพธิ์ทอง, แสวงหา, วิเศษชัยชาญ, สามโก้)
   - **การ์ดสรุปยอด 8 กลุ่มเปราะบางทั้งจังหวัด** พร้อมระบบค้นหารายชื่อสถานบริการทั้ง 59 แห่ง
   - **ระบบ Modal ตรวจสอบรายงานฉบับเต็มรายหน่วยงาน (Full Drill-down View):**
     - คลิก **"ดูฉบับเต็ม"** เพื่อเปิด Modal ป๊อปอัปขนาดใหญ่
     - มีแท็บ **"จำแนกรายหมู่บ้าน (แยกตามล็อกหัวข้อ)"** พร้อมปุ่มสลับล็อก 1 ถึง ล็อก 8 แสดงตารางตัวเลขของทุกหมู่บ้าน
     - มีแท็บ **"สรุปยอดรวมหน่วยงาน (8 กลุ่มเปราะบาง)"** และแท็บ **"ทีมปฏิบัติการ & การแพทย์เคลื่อนที่"**
     - มีปุ่ม **"พิมพ์รายงาน / บันทึก PDF"** สำหรับพิมพ์เอกสารราชการ

4. **ระบบบันทึก Audit Logs ตรวจสอบประวัติการทำงาน (Who, Where, What, NOW()):**
   - ทุกครั้งที่มีการบันทึกรายงาน หรือการแก้ไขข้อมูล ระบบจะบันทึก:
     - **วันเวลาที่ทำรายการ:** บันทึกด้วย `NOW()` (เวลาปัจจุบันของระบบ)
     - **วันที่ของรายงาน:** `report_date` ที่เกี่ยวข้องกับข้อมูลนั้น
     - **ใคร (Who):** ชื่อ-สกุล และ username ของผู้ปฏิบัติงาน
     - **ที่ไหน (Where):** อำเภอ, หน่วยงานสังกัด, และหมายเลข IP Address
     - **ทำอะไร (What):** การกระทำและรายละเอียดการเปลี่ยนแปลงข้อมูล
   - มีแท็บแสดงตาราง **ประวัติการปฏิบัติงานในระบบ (Audit Logs)** ในหน้า Admin ให้ตรวจสอบย้อนหลังได้ตลอดเวลา

5. **แบบฟอร์มเฉพาะส่วนที่ 3 การให้บริการด้านการแพทย์และสาธารณสุข (`medical_services.php`):**
   - แยกแบบฟอร์มตามไฟล์ Excel แถว 63–145 บันทึกข้อมูลการออกหน่วยบริการแพทย์และสาธารณสุขในพื้นที่:
     - **3.1 สถานที่ออกหน่วย**: ตำบล, หมู่ที่, ชื่อหมู่บ้าน, จำนวนผู้มารับบริการรวม
     - **3.2 ทีมปฏิบัติการ**: Mobile Clinic, MCATT, SRRT, ShERT
     - **3.3 การให้บริการ**: ส่งยาเรื้อรัง, เยี่ยมบ้าน, จ่ายยาชุด, สุขศึกษา, ตรวจรักษา, ส่งต่อ, บริการอื่น ๆ
     - **3.4 สุขภาพจิต (MCATT)**: ยอดคัดกรอง, ความเครียดสูง, เสี่ยงซึมเศร้า, เสี่ยงฆ่าตัวตาย, PFA, ส่งต่อแพทย์
     - **3.5 13 กลุ่มโรคที่พบบ่อย**: น้ำกัดเท้า, ผิวหนังผื่นคัน, ปวดกล้ามเนื้อ, ปวดศีรษะ, ตาแดง, ไข้เลือดออก ฯลฯ
     - **3.6 อุบัติเหตุจากน้ำท่วม**: จมน้ำ, ไฟฟ้าช็อต
     - **3.7 ทรัพยากร & ศูนย์พักพิง**: ยาสามัญ, ขี้ผึ้งน้ำกัดเท้า, ยาทาเชื้อรา, รองเท้าบูท, โลชั่นกันยุง, ถุงดำ, ถุงยังชีพ, ข้อมูลศูนย์พักพิง และชื่อ-เบอร์โทรผู้รายงาน

6. **Executive OnePage Infographic Dashboard (`onepage.php`):**
   - หน้าแดชบอร์ดสรุปสถานการณ์อุทกภัยด้านการแพทย์และสาธารณสุขจังหวัดอ่างทอง ออกแบบตามตัวอย่างภาพอ้างอิงของ สสจ.อ่างทอง:
     - Header ตรา สธ. และ ตราจังหวัดอ่างทอง
     - 4 Status Pills: 5 อำเภอ, 33 ตำบล, 146 หมู่บ้าน, 2,009 หลังคาเรือน
     - สภาพอากาศ และระดับน้ำ/อัตราการระบายน้ำหน้าศาลากลาง
     - แผนที่ SVG จังหวัดอ่างทอง ไฮไลท์อำเภอประสบภัยสีแดง และอำเภอปลอดภัยสีเขียว
     - ตาราง 7 อำเภอ, ตาราง 8 กลุ่มเปราะบาง, ตารางบริการแพทย์ และ 5 อันดับโรคที่พบบ่อย
     - บล็อกสรุปคัดกรองสุขภาพจิต, การสนับสนุนทรัพยากร/เวชภัณฑ์, ศูนย์พักพิง, และผลกระทบต่อสถานบริการ
     - รองรับปุ่มพิมพ์เอกสารขนาด A4 (Print to PDF) คมชัด พอดีหน้ากระดาษ
     - ปุ่ม 1-Click Load Demo Preset สำหรับโหลดชุดข้อมูลตัวอย่างที่ตรงกับภาพอินโฟกราฟิก
